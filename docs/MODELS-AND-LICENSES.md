# 模型与版权声明

本仓库（song-cover-kit）**只提供代码**。

## 1. 不含模型权重与素材

仓库里没有、以后也不应提交：

- RVC 声线模型：`.pth` / `.index`
- 人声特征基础模型：`hubert_base.pt`、`rmvpe.pt`
- 音源分离模型：demucs 权重
- 任何歌曲、人声、音频片段

`.gitignore` 已把这些类型排除。

代码和示例里也**不写任何具体声线模型名或路径**：`voices.example.json` 只用 `my_voice` /
`another_voice` 这类占位名，使用者想用什么声音，自己往 `voices.json` 里加。
这样做也是为了避免把别人的声线模型（以及模型名）带进仓库造成侵权或误导。

## 2. 你需要自己准备的东西

| 模型 | 用途 | 获取方式 |
|---|---|---|
| RVC 声线 `.pth` + `.index` | 决定换成什么声音 | 自行获取；确认你有权使用 |
| `hubert_base.pt` / `rmvpe.pt` | rvc-python 的基础模型 | rvc-python 项目说明 / RVC 原项目 |
| demucs 权重 | 分离人声/伴奏 | 首次运行自动下载（代码会拉取） |

这些模型各有各的许可证，**不是本仓库的一部分**，请遵守原作者的许可。

## 3. 使用边界

- 请只处理你有权使用的音频素材。
- 不要用本工具冒充他人、制作误导内容、侵犯他人声音权/肖像权/著作权，或做违法用途。
- 把别人的声音模型用于公开发布前，先确认模型作者的授权范围。
